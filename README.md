# VibeFit - 把等待 AI 跑完代码的时间变成运动场

## 项目简介
**VibeFit** 是一款专为开发者设计的 Chrome 扩展程序，旨在解决在 AI Studio 等开发工具中等待代码运行（Loading）时的枯燥与焦虑。它通过实时监测网页状态，在等待时自动触发 Tabata 运动提醒，将原本的**“无效等待时间”转化为“高效燃脂资产”**，让开发者的工作流充满活力与多巴胺。

---

## 核心技术突破 (Technical Breakthroughs)

### 1. 智能碎片合体雷达 (Fragment-Merging Radar)
为了精准捕捉 AI Studio 的运行状态，我们突破了传统标签匹配的局限。针对网页将运行时间拆分为碎片化 HTML 标签（如 `<span>Running for </span><span>63</span><span>s</span>`）的特性，我开发了**“碎片合体雷达”算法**。它能在监测时自动汇聚父节点下的所有文本碎片，强行揉合为完整字符串进行匹配，从而实现了 **0 误触发的精准监测**，并有效规避了在编辑器打字过程中的干扰。

### 2. 沉浸式 UI 与高性能渲染架构
在项目开发初期，我曾尝试直接加载 3D 模型以提升视觉体验，但由于浏览器插件环境的性能瓶颈及跨域抓取限制，导致模型无法稳定渲染，视频内容也难以顺畅嵌入。

为了打破这一局限，我重新设计了一套**“双层叠加沉浸式架构”**：
*   **底层基座**：通过“全屏白磨砂玻璃罩 (Frosted Glass Overlay)”建立沉浸式视觉基准，将用户的注意力自然聚焦至中心区域，有效弱化了 AI Studio 原生界面的干扰。
*   **表现层**：在磨砂罩之上，构建独立的**“悬浮视频弹窗 (Video Overlay Modal)”**。这种架构分离了视觉渲染与交互内容，有效规避了直接嵌入视频时可能出现的兼容性问题。
*   **优势**：这种设计不仅解决了 3D/视频无法稳定抓取的难题，还保证了 **`Liquid Glass` 的高级质感**，确保视频内容在任何网络环境下均能秒级启动与流畅循环，完美平衡了性能开销与审美表现。

---

## 核心功能
*   **无感状态监测**：利用 `MutationObserver` 实时感知 AI Studio 的代码运行状态，无缝触发。
*   **Tabata 健身引擎**：内置多种运动（如深蹲、登山跑），配合 `Web Audio API` 合成的电子节拍，提供沉浸式健身指导。
*   **多巴胺数据追踪**：自动记录完成的运动次数、累计时长与预估消耗卡路里。
*   **极简分享体验**：通过 `Canvas API` 一键生成红色流体玻璃质感（Liquid Glass）的运动成就卡，让开发者的每一滴汗水都有迹可循。

## 如何安装
1. **下载或克隆**此代码库。
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`。
3. 开启右上角的**“开发者模式 (Developer mode)”**。
4. 点击**“加载已解压的扩展程序 (Load unpacked)”**，选择项目文件夹。
5. 在 AI Studio 页面运行代码，体验 VibeFit。
